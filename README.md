# SQL Data Warehouse Project

## 📖 Overview

Welcome to the **SQL Data Warehouse Project** repository! 🚀

This project demonstrates the design and implementation of a modern Data Warehouse using SQL Server. It covers the complete data warehousing lifecycle, including data ingestion, ETL (Extract, Transform, Load) processes, dimensional modeling, and analytics-ready data preparation.

The goal of this project is to transform raw data from multiple sources into a structured, scalable, and business-ready data warehouse that supports reporting, analytics, and data-driven decision-making.

---

## 🏗️ Project Architecture

The project follows a Medallion Architecture consisting of **Bronze**, **Silver**, and **Gold** layers:

### Bronze Layer

* Stores raw data from source systems.
* Preserves data in its original format.
* Serves as the landing zone for data ingestion.

### Silver Layer

* Cleanses and standardizes data.
* Handles data quality checks and transformations.
* Creates a reliable and consistent data foundation.

### Gold Layer

* Provides business-ready data for analytics.
* Implements dimensional modeling using Fact and Dimension tables.
* Optimized for reporting and analytical workloads.
